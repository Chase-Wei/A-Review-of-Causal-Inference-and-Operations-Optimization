# A Review of Causal Inference and Operations Optimization

This project organizes notes, references, and draft material for a review on the intersection of causal inference and operations optimization.

## Scope

- Causal inference for data-driven decision making
- Treatment-effect estimation for operational policies
- Prescriptive analytics with causal structure
- Causal robust optimization and distribution shift
- Applications in supply chains, pricing, healthcare operations, and platform operations

## Repository Structure

- `docs/research-plan.md`: working outline and writing plan
- `references/README.md`: bibliography notes and paper-tracking conventions

## Working Questions

1. How can causal estimands improve operational decisions compared with purely predictive models?
2. When does confounding cause biased optimization decisions?
3. How can treatment-effect heterogeneity be integrated into prescriptive optimization?
4. What are the links between causal robustness, distributional robustness, and policy generalization?
